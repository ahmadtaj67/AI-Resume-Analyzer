# Portfolio Assets

## Professional Project Description

AI Resume Analyzer is a full-stack resume intelligence platform that helps users upload PDF resumes, extract readable text, generate AI-powered analysis reports, track report history, compare resume versions, and manage profile settings. The project includes a secure Express API, Supabase PostgreSQL persistence, JWT authentication, Gemini-powered structured analysis, and admin tools for user, report, settings, and analytics oversight.

## Short Project Summary

A full-stack AI Resume Analyzer with PDF upload, Gemini analysis, saved reports, resume comparison, JWT authentication, Supabase persistence, and admin analytics.

## Long Project Summary

AI Resume Analyzer is a production-ready full-stack web application built with React, Vite, Node.js, Express, Supabase PostgreSQL, JWT authentication, and Gemini AI. Users can register, upload selectable-text PDF resumes, receive structured recruiter-style analysis, save report history, open report details, compare two saved reports, and manage profile settings. Admin users can monitor platform statistics, manage users with soft delete/restore, review reports, update platform display settings, and view analytics for report trends and skills. The project is prepared for Vercel frontend deployment, Render backend deployment, Docker usage, and environment-driven production configuration.
